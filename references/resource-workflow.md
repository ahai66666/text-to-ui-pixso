# Stage resource queries
RULES_ROOT is this skill directory. Run query-resources.mjs with --stage, --view api and optional --out-dir outside the skill. Read task-pack.json OR task-pack.md, not both. read-plan.json is provenance/measurement metadata. Full indexes, component aggregates and source code are machine inputs.
Query --stage pixso --phase readiness|capture|compile|publish|readback; diagnosis is for requested converter investigation. --component <id> --mapping selects exact mapping rows. Normal import accepts a page without a generation Context Packet. Do not run HTML design stages. Execute the current phase only; query readiness does not itself publish. Use the route's managed plugin flow and retain current-run evidence.
Commands: resources:build → catalog:build → index:build, then corresponding checks and skill:manifest. Unknown IDs, ambiguity, stale sources and missing dependencies stop the query. --max-bytes rejects over-budget output without truncating rules. JSON UTF-8 byte counts are not Token counts. Other models receive only the current pack and confirmed decisions; a new conversation does not inherit the previous chat automatically.
