# Titlebar window-control icons

These 24×24 SVG assets are the approved user-supplied Titlebar controls.

- `window-minimize.svg` originates from `最小化.svg`.
- `window-maximize.svg` originates from `最大化.svg`.
- `window-close.svg` originates from `关闭.svg`.

The supplied geometry is preserved. Fixed black fills are normalized to `currentColor` so component state and theme tokens remain authoritative.
